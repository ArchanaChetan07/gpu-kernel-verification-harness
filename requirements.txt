# CRUCIBLE runtime dependencies.

# torch is deliberately NOT listed here. Every rented-GPU base image already
# ships a torch built against a specific CUDA version, and letting pip resolve
# torch from PyPI would silently swap it for the default-CUDA wheel, changing
# numerics underneath a tolerance model that was calibrated against the
# original build. The bootstrap script checks torch and installs it only if
# genuinely absent; the Dockerfile inherits it from the base image.
#
# Required: torch >= 2.4 with a working CUDA build (2.6.0+cu124 is the pinned
# development target). On Linux, triton ships inside the torch wheel.
